# Shivaay Dhondiyal – Immersive Portfolio

An interactive, cinematic portfolio that brings projects to life through 3D storytelling, smooth animations, and direct access to live deployed AI/ML applications.

## 🌐 Live Demo

Visit the portfolio at: [shivaaydhondiyal.online](https://shivaaydhondiyal.online)

## ✨ Features

- **Cinematic Intro**: A visually striking wormhole animation welcomes visitors, setting an immersive tone.
- **3D Project Explorer**: Navigate through projects in an interactive 3D space.
- **Live Project Access**: Launch connected AI/ML applications directly from the portfolio:
  - **Crowd Counting**: Real-time crowd density estimation
  - **Hand Gesture Recognition**: Gesture-based control
  - **Empathic AI Chatbot**: Emotion-aware conversational AI
- **Yggdrasil Tree**: Explore Shivaay's academic and professional journey through an interactive tree visualization.
- **Responsive Design**: Works beautifully on desktop and mobile devices.

## 🛠️ Technology (For Developers)

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **3D & Animation**: React Three Fiber, Three.js, GSAP
- **State Management**: TanStack Query, React Hook Form
- **Deployment**: Netlify
- **Optional**: Tauri for desktop application
